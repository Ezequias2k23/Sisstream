# SISSTREAM

Sistema de gerenciamento de uma plataforma de streaming desenvolvido para a disciplina de Banco de Dados.

## Tecnologias utilizadas

- Python
- PostgreSQL
- psycopg2

## Funcionalidades

- Cadastro de usuários
- Cadastro de produções
- Avaliação de produções
- Relatório de média de avaliações por produção (JOIN + GROUP BY)

## Como executar

1. Criar o banco no PostgreSQL
